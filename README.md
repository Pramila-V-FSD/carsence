1. What did you build and why? What did you deliberately cut?
Built: CarSense — A car research platform with a matching quiz, spec comparison table, and an AI chat advisor to help buyers choose the right car.
Cuts: User login (accounts), image uploads, unit test files, and dealer price integration.
2. What’s your tech stack and why did you pick it?
Stack: React, Node.js (Express), MongoDB, and Tailwind CSS.
Why: It is fast to develop, handles flexible car data (MongoDB), and allows quick styling (Tailwind).
3. What was delegated to AI vs. done manually?
AI Help: Generated mock car data (specs/reviews) and basic boilerplate code.
Manual Work: App structure, comparison logic, offline SVG placeholders, and CSS layout styling.
AI Pros: Saved hours creating realistic car data.
AI Cons: Buggy custom animations and refactoring code too much.
4. What would you add with another 4 hours?
Visual price graphs/trends.
Automated tests (checking if the quiz works).
PWA support (making it work offline).
